# Contributing to the project
Thanks for interest in contributing to this project
## Development setup:
1. ### Prerequesites:
- Node.js (18+)
- Python (3.13.13)
2. **Clone the repo** `git clone https://github.com/Iqlas66/FLVX.git`
3. **Cd into Flux** `cd Flux`
4. Install Python dependencies `pip install requests keyring cryptography
`
5. Cd into electron-app `cd electron-app`
6. Install Node.js dependencies `npm install`
7. Run dev `npm run dev`
## Folder structure:
- `main.py` - main file
- `wallpaper.py` - wallpaper stuff
- `visa.py` - visa related and also drawing cards
- `electron-app` - ui and api part
- `/electron-app/src/renderer/src/App.jsx ` - main ui part
- `/electron-app/src/main/index.js` - api handler  the app resolution and appearance in the tray
